# Code of Conduct

We want RAG Agent to be a welcoming, respectful, and constructive project for everyone.

## Expected behavior

- Be respectful and considerate.
- Give actionable feedback and assume good intent.
- Focus criticism on ideas and code, not people.
- Welcome different experience levels and backgrounds.
- Respect privacy; never publish someone else's personal information or secrets.

## Unacceptable behavior

Harassment, discrimination, personal attacks, deliberate intimidation, and publishing private information without permission are not acceptable.

## Enforcement

Project maintainers may edit, remove, or reject contributions and may block participation for behavior that violates this code. To report a concern, contact the repository owner privately through their GitHub profile. Do not post sensitive details in a public issue.

This code applies to project issues, pull requests, reviews, and other project spaces.
